# Advanced Digital Shadow System

A real-time interactive AI visual experiment using webcam-based face tracking, hand tracking, gesture control, holographic objects, and JARVIS-style visual annotations.

## Features

- Real-time webcam input
- Face tracking
- Hand and finger tracking
- Pinch gesture to create polygon hologram
- Open palm gesture to create cube hologram
- Two-hand control to rotate and scale holograms
- AI mesh visual mode
- Clean JARVIS-style interface
- Fixed AI object analysis panel
- Particle effects and targeting laser
